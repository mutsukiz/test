# マルチIMU脚状態推定プロトタイプ(平面2リンク脚)

四足歩行ロボットの四肢にIMUを分散配置し、センサフュージョンにより
**胴体姿勢**と**関節の低剛性によるズレ(たわみ δ = リンク角 − モータ角)**を
同時推定する手法の最小構成プロトタイプ。依存は numpy / matplotlib のみ。

## ファイル構成

- `sim.py` — 平面2リンク脚シミュレータ。胴体ピッチ+並進、股・膝関節、
  関節弾性(負荷トルクに対する2次系応答としてたわみ真値を生成)、
  IMU×3(胴体/大腿/下腿: ジャイロバイアス・ノイズ付き)、エンコーダ(量子化)。
- `estimator.py` — Error-State EKF。状態 [θ0, δ1, δ2, b0, b1, b2]。
- `demo.py` — 実行・評価・可視化(`result.png` を出力)。

## 手法の要点

**予測**: 隣接リンクのジャイロ差分 − エンコーダ速度 = たわみ速度、
という運動学的恒等式でδを積分。胴体ジャイロでθ0を積分。

**更新(1) 胴体傾斜**: 加速度計の重力方向。歩行中は動的加速度で大きく
汚れる(本シミュレーションで1σ≈26°)が周期運動では不偏なため、
大きな観測分散で緩く当ててθ0とb0のドリフトのみ抑える。

**更新(2) リンク比力残差(本手法の核)**: 胴体加速度計から胴体点の
並進加速度を復元し、ジャイロ角速度・角加速度で運動学チェーンを伝播して
各リンクIMU位置の比力を予測。実測との残差はリンク間の相対角=δに
鋭敏であり、δの絶対値を強く拘束する。ヤコビアンは数値微分。
素朴な「加速度計=傾斜計」観測は脚のスイング中に破綻する(実験で確認済み)
ため、この動的加速度補償が精度の鍵。

角加速度はジャイロのゼロ位相平滑化+微分で推定(オフライン)。
オンラインでは同等のFIR微分器(固定ラグ数ms)で置き換え可能。

## 実行

```bash
python demo.py
```

代表結果(500 Hz, 10 s, 歩容1.5 Hz, 関節剛性 60/40 Nm/rad):

| 量 | マルチIMU ESKF | 比較 |
|---|---|---|
| 胴体ピッチ RMSE | 1.2° | 単一胴体IMU: 2.3° |
| δ1(股)RMSE | 0.05° | 剛体仮定: 1.94° |
| δ2(膝)RMSE | 0.06° | 剛体仮定: 0.57° |

たわみ推定は剛体仮定に対し10〜36倍の精度。角加速度に真値を与えた
上限性能は δ≈0.04° で、実装はほぼ上限に到達している。

## 関連研究(2023–2025)

- **MIPO** (Yang et al., IROS 2023, CMU): 胴体+足IMUのEKF。足IMUで
  足先速度更新・接触/スリップ検出。位置ドリフト大幅減。
- **Cerberus 2** (2023–): マルチIMU脚オドメトリのファクターグラフ統合。
  足リンク姿勢を状態に含めることが可観測性維持に重要と指摘。
- **DogLegs** (Wu et al., 2025): 胴体IMU+各脚下腿IMU+エンコーダの
  error-state EKF。関節柔軟性・バックラッシュ下で劣化する運動学モデル
  への依存を減らせると明言。本プロトタイプに最も近い先行研究。
- **LMIPSE** (2025): 胴体+4足IMUのRI-EKF+CNNによる学習補助。
- **TALOS股関節たわみ推定** (2022): IMUで計測不能な弾性たわみを推定し
  等価剛体関節角へ集約(二足)。

「脚IMUによる浮遊ベース推定」と「たわみ推定」を四足で統合し、
たわみを明示的な状態量として扱う点は研究上の新規性の余地がある。

## 3D・実機への拡張ロードマップ

1. **3D化**: 姿勢をSO(3)(クォータニオン)に、error-stateを接空間で定義。
   関節たわみは1軸のまま(各関節の回転軸まわり)。invariant EKF (InEKF)
   化するとMIPO/DogLegs系との比較がしやすい。
2. **浮遊ベース位置・速度の追加**: 接触足のゼロ速度更新(脚オドメトリ)を
   観測に追加。接触判定は足IMU加速度の分散 or 関節トルクで。
3. **4脚化**: 状態を [ベース姿勢/速度/位置, 各脚δ(8〜12), 各IMUバイアス]
   に拡張。脚ごとに更新(2)を独立適用。
4. **実機**: IMU取り付け位置・姿勢の外部キャリブレーション
   (静止+既知動作での同定)、IMU間の時刻同期、加速度計バイアスの
   状態追加、エンコーダ速度のノイズ特性同定。
5. **異常検知**: 推定δの統計(移動平均・分散)を監視し、閾値超過で
   剛性低下・バックラッシュ増大・締結ゆるみを警報。

## チューニングの勘所

- `link_acc_sigma`: 角加速度推定誤差 × IMU取り付け距離 が支配的。
  取り付けを関節近くにすると小さくでき、δ精度が上がる。
- `incl_sigma`: 歩容の動的加速度の大きさに合わせる(大きめが安全)。
- `bias_walk`: 小さくするとバイアス収束は遅いが滑らか。
